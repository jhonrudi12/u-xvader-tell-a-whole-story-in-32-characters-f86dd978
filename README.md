Tell a Whole Story in 32 Characters: **Ex took the dog. I kept the WiFi** — a breakup in two beats. The ex took the dog; the narrator kept the WiFi, the real prize of the split. A small Python program scores a shortlist of candidate network names against the judge's brief (on-subject joke first, then lands on first read, then whole story, then fresh, then tight) and writes the winning name to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
